# Proyecto
 LockSense

## Descripción

LockSense es un sistema de casilleros inteligentes basado en tecnologías IoT, diseñado para proporcionar un acceso seguro y automatizado a espacios de almacenamiento, mediante el uso de tarjetas RFID/NFC y reconocimiento facial, además de sensores y cámara que permiten supervisar el estado y actividad de los casilleros

## Funcionalidades
**Accesos Inteligentes**

-Acceso mediante tarjeta RFID/NFC

-Reconocimiento facial mediante cámara

-Cierre automático al cerrar la puerta.

-Bloqueo temporal después de varios intentos fallidos.

**IA y seguridad**

-Detección de anomalías mediante cámara y/o análisis de comportamiento.

-Alarma ante un acceso no autorizado.

-Análisis de patrones de uso y detección de comportamientos inusuales.

**Registro y monitoreo**

-Registrar todos los accesos.

-Registrar intentos de acceso no autorizados.

-Notificar intentos de acceso.

-Registrar cuánto tiempo permanece abierto el casillero.

-Consultar el estado del casillero (abierto, cerrado, bloqueado).

**Aplicación/PWA del Usuario**

-Inicio de sesión con usuario o identificador y contraseña.

-Registro del rostro desde el propio dispositivo del usuario 
 
 **Panel Administrativo**

-Gestionar usuarios.

-Asignar casilleros a usuarios.

-Liberar casilleros cuando el usuario deja de tener derecho a él.

-Bloquear casilleros.

-Administrar casilleros.

-Consultar estadísticas de uso.

**Panel Superadmin**

-Gestionar organizaciones

-Estadisticas globales

-Configuración del casillero
